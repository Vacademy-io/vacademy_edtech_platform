## `find_batch`

**Batches: view** · Read only

Find batches by name, see who is enrolled in a batch, and list who enrolled in a date range (name, email, batch and status).

<Accordion title="Parameters">

<ParamField path="query" type="string" required>

</ParamField>

</Accordion>

<Accordion title="What your AI app is told about this tool">
