## `learner_report`

**Progress reports: view data** · Read only

Let the connected AI app read the data behind a learner's progress report — attendance and every live class, test scores with rank and class average, marks by subject, study time and what was studied, course progress next to the batch average, assignments with feedback, doubts with their replies and the analysis of each attempt — plus the reports already generated in the dashboard, so it can write the report for you. Read-only. The AI app writes the report itself, so it uses no AI credits.

| Action | What it does |
| :--- | :--- |
| `guide` | what every field means, the dashboard report's status/grade rules and how to write a grounded report. Read it once before writing. |
| `data` | `report` = the facts the dashboard report is built from (attendance, live classes, assessments with rank/percentile/class average, marks by subject, study habits, course progress, certificates, assignments, doubts, logins, topic mastery / Bloom's / confidence / misconceptions); `detail` = what that report throws away (every live class, per-module progress next to the batch average, what was studied slide by slide, assignment submissions with feedback, the doubts' text and replies, and the analysis of each attempt). Ask for only the modules / detail the admin's report needs when the window is long. |
| `saved_reports` | progress reports already generated in the dashboard (to compare periods). |
| `saved_report` | one of them in full. |
