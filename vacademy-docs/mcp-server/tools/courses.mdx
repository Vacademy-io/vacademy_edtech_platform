## `course_structure_edit`

**Courses: change structure / depth** · Makes changes · Changes live data — the change applies straight away. · Turned on separately (opt-in)

Let the connected AI app change how many levels a course has (subjects / modules / chapters) or regroup its content — for example turn a chapters-only course into modules of chapters, with groups it proposes from the content and you adjust. It always shows you the new structure first and changes it only after you confirm. Works on live courses too: learners see the new structure at once and keep their slide progress. Nothing is copied or deleted.

<Note>
**What keeps it safe:** LIVE, confirm-gated, the admin's explicit choice: changes a course's depth / grouping in ONE admin-core transaction for every batch; nothing is copied or deleted — slides and kept containers keep their ids, emptied containers are soft-deleted; refuses content shared with another course and trees that drop or duplicate a slide; every write needs the confirm_token of a dry-run preview of the identical request
</Note>

| `apply` | does it, after the admin said yes to the preview. |
