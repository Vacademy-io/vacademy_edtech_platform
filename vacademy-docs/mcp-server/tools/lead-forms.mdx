## `audience_forms`

**Lead forms: view** · Read only

See lead campaigns: their form fields, where they are used on the websites, and leads received.

| Action | What it does |
| :--- | :--- |
| `list` | every campaign with objective, form field count, leads received, last lead, and which website pages use it. |
| `get` | one campaign with its form fields (label, type, required) and its public form URL. |
| `leads` | the most recent leads — name, when, from which page, conversion status. Contact details are included only when the caller may see them. |

## `audience_forms_edit`

**Lead forms: edit** · Makes changes · Adds only — never changes or removes what exists.

Create lead campaigns, add fields to their forms and send test leads. Never removes anything.

<Note>
**What keeps it safe:** additive: creates campaigns / adds fields / sends a test lead; never removes
</Note>

| Action | What it does |
| :--- | :--- |
| `create` | a new WEBSITE lead campaign. Default fields: Full Name, Email, Phone Number. Returns the id to use with website_edit(action='link_lead_form'). |
| `update_fields` | add fields to the form or change existing ones (matched by label). Existing fields are never removed here — that stays in Audience Manager. Get the current list with audience_forms(action='get'). |
| `send_test_lead` | submit one test lead through the real public pipeline to prove the campaign receives submissions. |
