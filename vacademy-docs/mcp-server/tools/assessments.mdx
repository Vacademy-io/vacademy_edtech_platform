## `find_assessment`

**Assessments: view** · Read only

Find tests (live, upcoming or past) with registration and attempt counts, see each participant's attempt, score, grading status and whether their result is released, and the ranked leaderboard.

<ParamField path="name" type="string">

</ParamField>
<ParamField path="window" type="string">

</Accordion>
