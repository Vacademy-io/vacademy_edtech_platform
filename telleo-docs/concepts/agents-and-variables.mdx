An **agent** is a configured AI caller: its voice, language, opening line, script, the questions it asks and the labels it can give a call. You create and edit agents in the dashboard (**CRM → Calling → AI Agents**) or, with the `agents:manage` scope, [through the API](/concepts/managing-agents); each call chooses its agent with `agent_id`.

## Listing agents

```bash
curl https://api.telleo.ai/v1/agents -H "X-API-Key: $TELLEO_API_KEY"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "17ea33d2-5b6c-4c1e-9a1f-2d4e6f8a9b0c",
      "object": "agent",
      "name": "Riya – admissions",
      "language": "en-IN",
      "enabled": true,
      "direction": "outbound",
      "voice": "hi-IN-Chirp3-HD-Kore",
      "tts_model": "google",
      "updated_at": "2026-10-19T10:15:00Z",
      "uses_contact_name": true,
      "variables": ["course", "city"]
    }
  ],
  "has_more": false
}
```

Only agents that are **turned on** and can **call out** are listed; add `?include_disabled=true` to list every agent, including those turned off and inbound-only ones. `GET /v1/agents/{id}` returns one agent's whole configuration. Using one that is turned off returns `409 agent_disabled`; an inbound-only agent returns `409 agent_inbound_only`. If an agent is turned off while calls are waiting for it in the queue, those calls are canceled, not dialled with another voice — whether they came from the API, a workflow, a bulk campaign or the dashboard. API calls whose agent is deleted are canceled too.

## Personalising the call

Agent scripts contain placeholders in double braces, such as:

> Hi {{name}}, this is Riya from Shiksha Academy. You enquired about {{course}} in {{city}} — is this a good time?

You fill them per call:

```json
{
  "agent_id": "17ea33d2-5b6c-4c1e-9a1f-2d4e6f8a9b0c",
  "phone_number": "+919876543210",
  "contact": { "name": "Asha Verma" },
  "variables": { "course": "NEET 2027", "city": "Indore" }
}
```

- **`{{name}}`** comes from `contact.name`. When `uses_contact_name` is `true`, always send it: an agent that does not know the name greets the person without it.
- **Everything else** comes from `variables`, including `{{institute_name}}`, `{{lead_source}}` and `{{booked_slot}}` when the script uses them. The `variables` list on each agent shows exactly which keys its script uses.
- **Date and time** placeholders (`{{day}}`, `{{today}}`, `{{date}}`, `{{time}}`, `{{datetime}}`, `{{now}}`, `{{tomorrow}}`, `{{year}}`, `{{month}}`) are filled with the current date and time. A variable with one of these names, or named `name` or `lead_name`, is accepted but never replaces the built-in value: `{{date}}` is always today and `{{name}}` always `contact.name`. The agent still receives it as information about the contact, and the response carries a `warnings` entry (`reserved_variable`) so you can rename it.

### Rules for variables

| | Limit |
|---|---|
| Number of variables | 50 per call |
| Key | Starts with a letter; letters, digits, `_` and spaces; up to 40 characters |
| Value | Text, a number or `true`/`false`; up to 500 characters |

Variables are spoken by the agent, so send them the way a person would say them: `"NEET 2027"`, not `"neet_2027_batch_b"`.

<Tip>
Keep data the agent should **not** say in `metadata` instead. It is stored with the call and returned to you, but never shown to the agent.
</Tip>

## What agents do differently on API calls

Agents can be set up in the dashboard to send WhatsApp messages or emails, or to book meetings, during or after a call. On API calls they do **not** offer or send these: the contact belongs to your CRM, not to Telleo's. When the contact agrees to a meeting, the agreed time comes back in [`outcome.meeting`](/concepts/outcomes); book it and send any follow-up from your own systems.

## The contact

| Field | Purpose |
|---|---|
| `contact.name` | How the agent addresses the person (up to 120 characters; longer is rejected). |
| `contact.email` | Stored with the call and returned to you. |
| `contact.external_id` | Your id for this person (CRM record id, lead id; up to 255 characters). Filter calls with `GET /v1/calls?external_id=`. |
